## 1. Design Direction & Persona

* **Aesthetic Direction**: **Organic Eco-Tech**
* **Brand Attributes**: High-Contrast Utility, Clean, Grounded, Scientific, Intuitive.
* **Core Metaphor**: Sự giao thoa giữa sinh thái thực vật tự nhiên (Organic) và thị giác máy tính chính xác cao (Eco-Tech Precision).
* **Anti-Slop Directives**:
  * Banned: Generic AI purple-to-blue gradients, floating pink bubbles, nested cards > 2 levels.
  * Banned: Pure black (`#000000`), dead grey (`#808080`), grey-on-grey text.
  * Hierarchy: Visual separation achieved via surface tone stepping and generous whitespace, never thick visual borders.

## 3. Accessibility & Contrast Safeguards (WCAG Strict)

1. **The Lime-Neon Law (#CFFF74)**:
   * **STRICT BAN**: NEVER place white text (`#FFFFFF`) or cream text (`#F7F8F1`) on top of `#CFFF74`. (Contrast ratio < 1.3:1 — Complete failure).
   * **MANDATORY**: Any text, icon, or visual glyph rendered inside or over a `#CFFF74` container MUST use Dark Moss (`#2F3A10`) or Deep Forest Night (`#111609`). (Contrast ratio > 11.5:1 — Exceeds WCAG AAA).
2. **Text Readability Standards**:
   * Minimum body font size: `15px` / `15dp`.
   * Secondary text (`#5A6640` on Light, `#A3B18A` on Dark) must maintain at least 4.5:1 contrast against its immediate underlying surface.
3. **Interactive Touch Targets**:
   * Minimum tap area: `44x44dp` on Mobile, `36x36px` on Web.
   * Visual active state feedback: Subtle scale (0.97) or background brightness shift (0.85 opacity).

## 4. Cross-Platform Technical Constraints

### 4.1. Mobile Client (React Native / Expo — Yoga Engine Rules)
* **Allowed Styling**:
  * Flexbox: `flex`, `flexDirection`, `alignItems`, `justifyContent`, `flexWrap`.
  * Layout: `gap`, `rowGap`, `columnGap`, `padding`, `margin`, `aspectRatio`.
  * Dimensions: Fixed `dp` values, percentages (`'100%'`), or dynamic via `Dimensions` / `useWindowDimensions`.
  * Shapes: `borderRadius`, `borderWidth`, `borderColor`, `overflow: 'hidden'`.
* **Strictly Banned on Mobile (Web-Only CSS Features)**:
  * ❌ NO `clamp(min, val, max)`
  * ❌ NO `minmax()` or CSS Grid (`grid-template-columns`)
  * ❌ NO modern CSS color functions (`oklch()`, `lab()`, `color-mix()`)
  * ❌ NO arbitrary string math (`calc(...)`) inside native style objects
* **Color Formats**: Hexadecimal (`#RRGGBB`) or `rgba(R, G, B, A)` strings only.

### 4.2. Web Server (Next.js / Tailwind CSS Integration)
* **Theme Mapping**: Export tokens to `tailwind.config.js` or Tailwind v4 `@theme` directive matching the exact token keys (`colors.eco.lime`, `colors.eco.moss`, `colors.eco.cream`).
* **Responsive Hierarchy**:
  * Mobile viewports (`< 768px`): Match React Native mobile experience layout.
  * Desktop viewports (`>= 1024px`): Expand navigation to Left Sidebar; layout dense tables and analytical Bento Grids.

## 6. Audit & Critique Quality Checklist

When evaluating components or screens (`/audit`, `/critique`, `/harden`):
* [ ] Is the primary CTA using `#CFFF74` with text `#2F3A10`?
* [ ] Are there zero generic blue/purple AI gradients?
* [ ] Is the card nesting level $\le 2$?
* [ ] Does the screen handle all 4 states: Loading, Empty, Error, and Populated?
* [ ] Are all touch targets $\ge 44 \times 44\text{dp}$ with $\ge 8\text{dp}$ spacing?
* [ ] Is text overflow protected by truncation / ellipsis?
* [ ] Are all colors referenced from tokens, without raw arbitrary hex values in components?
